# 黑马记账 🐎

黑马记账是一个**简单好用的个人记账桌面应用**，支持 Windows 和 macOS，帮你轻松记录每一笔人民币花销。

> A simple, easy-to-use personal expense tracking desktop app for Windows & macOS (UI in Chinese).

## ✨ 功能特性

- 💰 **记一笔**：支出 / 收入任意记，输入金额（人民币，支持两位小数）、选择日期、填写备注
- 🗂️ **两级分类**：支出 10 大类 + 收入 5 大类，记账归类一目了然
- 📋 **账单列表**：按时间倒序查看所有账单，收入绿色、支出主题色区分，底部显示支出 / 收入 / 结余
- 🔍 **搜索筛选**：按金额 / 日期 / 分类 / 备注搜索，分类下拉快速过滤
- ✏️ **修改账单**：双击或点「修改」即可改正记错的账，不用删了重记
- 🗑️ **安全删除**：勾选确认后删除（可随时退出勾选模式），误删数据进回收站可随时恢复
- 📊 **收支统计**：今天 / 本周 / 本月 / 今年 / 自定义时间段的总收入、总支出、结余，附分类占比环形图
- 🎨 **主题换色**：活力橙 / 清新蓝 / 自然绿 / 优雅紫 / 樱花粉五套主题一键切换
- 🌐 **中英双语**：设置里可切换简体中文 / English
- 💾 **本地存储**：数据保存在本地 SQLite 数据库，关闭软件不丢失
- 🖱️ **醒目操作**：大号橙色「记一笔」按钮，一眼就能找到

## 🚀 构建与运行

### Windows

前置条件：Visual Studio（C++ 工作负载）+ Qt 6.8（MSVC 版）

1. **编译**：双击 `tools\build.bat`
2. **运行**：双击 `tools\run.bat`
3. **创建桌面快捷方式**：右键 `tools\create_shortcut.ps1` → 使用 PowerShell 运行

### macOS

安装 Qt 6 后，用 CMake 编译即可（代码本身跨平台，无需改动）：

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/path/to/Qt/6.8.3/macos
cmake --build build
```
